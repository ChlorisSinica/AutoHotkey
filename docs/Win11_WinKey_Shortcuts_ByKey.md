# Windows 11 Win キー ショートカットキー一覧 (キー順)

> 対象: Windows 11 (23H2/24H2)
> 作成日: 2026-04-13
> カテゴリ別一覧: [Win11_WinKey_Shortcuts.md](Win11_WinKey_Shortcuts.md)

凡例:
- **新規** = Win11 で新たに追加
- **変更** = Win10 から機能が変更
- (空き) = OS 標準では未割当
- `AHK` = AutoHotkey で割当済み (詳細は末尾の [AHK 割当一覧](#ahk-割当一覧) を参照)
- `AHK(上書)` = OS 機能を AHK で上書きして別機能に割当
