# Windows 11 Win キー ショートカットキー一覧

> 対象: Windows 11 (23H2/24H2)
> 作成日: 2026-04-13

---

## 1. システム / 全般

| ショートカット | 説明 | Win11 新規/変更 |
|---|---|---|
| **Win** | スタートメニューの開閉 | - (デザイン変更) |
| **Win + D** | デスクトップの表示/復元 (トグル) | - |
| **Win + E** | エクスプローラーを開く | - |
| **Win + I** | 設定を開く | - |
| **Win + L** | PC をロック | - |
| **Win + M** | すべてのウィンドウを最小化 | - |
| **Win + Shift + M** | 最小化したウィンドウを復元 | - |
| **Win + X** | クイックリンクメニュー (電源ユーザーメニュー) | - |
| **Win + R** | 「ファイル名を指定して実行」を開く | - |
| **Win + Pause** | 設定 > システム > バージョン情報 | - |
| **Win + F** | フィードバック Hub を開きスクリーンショット取得 | - |
| **Win + , (カンマ)** | デスクトップを一時的にプレビュー (押し続ける) | - |
| **Win + Home** | アクティブウィンドウ以外を最小化/復元 (Aero Shake) | - |
| **Win + V** | クリップボード履歴を開く | - |
| **Win + P** | 表示モード切替 (PC画面のみ/複製/拡張/セカンドスクリーンのみ) | - |
| **Win + K** | ワイヤレスディスプレイに接続 (キャスト) | - |
| **Win + O** | デバイスの画面回転ロック (タブレット) | - |
| **Win + Y** | Windows Mixed Reality とデスクトップの入力切替 | - |
| **Win + Ctrl + F** | ネットワーク上のデバイス検索 (ドメイン環境) | - |
| **Win + Ctrl + Q** | クイックアシストを開く | - |
| **Win + Ctrl + Shift + B** | ブラックスクリーンからの復帰 | - |
| **Win + C** | Microsoft Copilot を開く | **変更** (Win10 では Cortana) |
| **Win + J** | Recall を開く (AI タイムライン) | **新規 (24H2)** |
| **Copilot キー** | Copilot を起動 (対応キーボードのみ) | **新規** |

## 2. ウィンドウ管理 (スナップ / 仮想デスクトップ)

### スナップ・ウィンドウ配置

| ショートカット | 説明 | Win11 新規/変更 |
|---|---|---|
| **Win + ↑** | ウィンドウを最大化 / 最大化済みなら上半分にスナップ | - (上半分スナップは新規) |
| **Win + ↓** | 最大化の解除、または最小化 | - |
| **Win + ←** | 画面左半分にスナップ | - |
| **Win + →** | 画面右半分にスナップ | - |
| **Win + Alt + ↑** | 画面上半分にスナップ | **新規** |
| **Win + Alt + ↓** | 画面下半分にスナップ | **新規** |
| **Win + Z** | スナップレイアウトを開く (レイアウト選択) | **新規** |
| **Win + Shift + ↑** | ウィンドウを縦方向に最大化 (幅は維持) | - |
| **Win + Shift + ↓** | 縦最大化を元に戻す | - |
| **Win + Shift + ←** | ウィンドウを左のモニターに移動 | - |
| **Win + Shift + →** | ウィンドウを右のモニターに移動 | - |
| **Win + Shift + Enter** | UWP アプリの全画面切替 | - |

### 仮想デスクトップ

| ショートカット | 説明 | Win11 新規/変更 |
|---|---|---|
| **Win + Tab** | タスクビューを開く (全ウィンドウ + 仮想デスクトップ一覧) | - (デザイン変更) |
| **Win + Ctrl + D** | 新しい仮想デスクトップを作成 | - |
| **Win + Ctrl + F4** | 現在の仮想デスクトップを閉じる | - |
| **Win + Ctrl + ←** | 左の仮想デスクトップに切替 | - |
| **Win + Ctrl + →** | 右の仮想デスクトップに切替 | - |

## 3. タスクバー

| ショートカット | 説明 | Win11 新規/変更 |
|---|---|---|
| **Win + T** | タスクバー上のアプリを順にフォーカス (順方向) | - |
| **Win + Shift + T** | タスクバー上のアプリを順にフォーカス (逆方向) | - |
| **Win + B** | システムトレイ (通知領域) にフォーカス | - |
| **Win + [0-9]** | タスクバーの該当位置のアプリを起動/切替 | - |
| **Win + Shift + [0-9]** | 該当位置のアプリの新しいインスタンスを起動 | - |
| **Win + Ctrl + [0-9]** | 該当位置のアプリの最後のアクティブウィンドウに切替 | - |
| **Win + Alt + [0-9]** | 該当位置のアプリのジャンプリストを開く | - |
| **Win + Ctrl + Shift + [0-9]** | 該当位置のアプリを管理者として起動 | - |

## 7. 入力 (絵文字 / 音声 / IME)

| ショートカット | 説明 | Win11 新規/変更 |
|---|---|---|
| **Win + . (ピリオド)** または **Win + ;** | 絵文字パネルを開く (顔文字, 記号, GIF, クリップボード含む) | - (Win11 で拡張) |
| **Win + H** | 音声入力 (ディクテーション) を開く | - (Win11 でリデザイン) |
| **Win + Alt + H** | 音声入力ダイアログにフォーカス | **新規** |
| **Win + Space** | 入力言語/キーボードレイアウト切替 (順方向) | - |
| **Win + Shift + Space** | 入力言語/キーボードレイアウト切替 (逆方向) | - |
| **Win + Ctrl + Space** | 前回選択した入力方式に変更 | - |
| **Win + /** | IME 再変換の開始 | - |
| **Win + Alt + K** | システム全体のマイクミュート切替 | **新規** |

| **Win + Ctrl + V** | サウンド出力クイック設定 (22H2+) |
| **Win + Alt + K** | システムマイクミュート切替 |
| **Win + Alt + H** | 音声入力ダイアログフォーカス |
| **Win + Alt + B** | HDR 切替 |
